# 内容管理手册

## 管理入口

访问 `/admin`。首次在本机创建管理员后即可登录。左侧包含作品、媒体与附件、开发计划、Demo 版本、管理员和站点资料。

## 发布一件作品

1. 新建作品，填写名称、唯一网址标识、简介、详细介绍和作品类型。
2. 按需上传封面、截图及附件。媒体默认私有；要展示的素材应开启“允许公开访问”。
3. 设置技术标签、项目状态、项目最近更新日期。完成度可以不填或不显示。
4. 添加在线体验、源码、发布页或视频链接。链接按钮名称可自定义。
5. 先保存草稿，使用预览按钮检查。预览仅管理员可见。
6. 设置可见性为公开，再发布。选中“精选作品”可出现在首页精选区；推荐顺序较小的优先。

保存草稿与发布不同。已经公开的作品仍可继续编辑草稿，确认后再发布新版本。历史版本页可以对比与恢复内容。

## 发布和回退 Demo

1. 将静态网页打为 ZIP，确保根目录或单一顶层目录有 `index.html`，资源使用相对路径。
2. 在 Demo 版本中新建并上传，等待“可发布”状态。失败时查看验证说明，修正后新建另一个版本。
3. 使用预览检查真实页面。预览链接短时有效，过期后重新从后台打开。
4. 编辑对应作品，将“发布的在线 Demo”关联到这个版本，然后发布作品。
5. 要回退时，把关联改为旧版本并重新发布。旧包不会因上传或切换被覆盖。

Demo 版本不能原地更换文件或在后台删除，以保留回退能力。媒体和 Demo 包占用持久化存储，清理历史资源前应备份并确认引用关系。

## 撤下内容

将作品或计划设为“不公开”并保存生效；前台详情、公开 API 和作品下载入口将不再提供该记录。作品开发状态“已归档”只表示开发阶段，不会自动撤下页面。

媒体拥有独立权限。若还需要撤销某文件的直接访问，请同时关闭该媒体的公开开关。

## 个人资料与开发计划

站点资料中修改名称、首页介绍、关于我、技能和联系方式。邮件地址使用 `mailto:地址`，其余使用完整网址。

开发计划可以关联作品，按计划中、进行中、已完成管理。目标日期可不填。站点资料中的栏目开关关闭后，前台导航和计划页面一起关闭。

## 内容来源提醒

现有 25 条记录是历史快照，不代表已重新检查每个项目的运行状态。封面占位图只是站点图形，不是软件截图。发布对外宣传前，请按实际情况更新文字、日期、链接并补充真实媒体。
