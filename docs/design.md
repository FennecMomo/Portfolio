## 内容模型

- `projects`：标题、slug、简介、富文本、封面、截图、类型、技术标签、项目状态、历史状态、完成度及开关、项目更新时间、精选、顺序、链接、附件、当前 Demo、可见性和 Payload 发布状态。
- `media`：文件、替代文字、说明、公开开关。默认私有，公开素材持有地址即可访问；不能把公开素材当作私密文件。
- `plans`：标题、说明、todo/doing/done、可选目标日期、关联作品、可见性及发布状态。
- `demos`：独立 ZIP 版本、验证状态、验证说明、内部入口目录。通过作品关联决定公开版本。
- `site-settings`：名称、介绍、关于我、头像、技能、联系方式、计划栏目开关。
- `users`：管理员账号，访客无需注册。

项目开发状态与内容发布状态独立；项目最近更新日期与后台内容修改时间独立。计划日期表示目标日期，不冒充完成日期。

## 数据迁移

`data.json` 的 25 条记录按原 ID 作为 slug 导入。原 `/project/:slug` 永久重定向到 `/works/:slug`。公开文字保留，标签按分隔符拆分，简介中的 HTML 换行转换为文本。

运行中、日常使用、已发布映射为“已发布”；维护中、已完成、暂停中保留相应含义；已归档与已废弃映射为“已归档”；开发中、重构中、待找回、待合并映射为“开发中”。所有原始状态保存在 `legacyStatus`，方便进一步人工整理。

导入通过 slug 检查已存在记录，重复执行不覆盖编辑结果。不会编造图片、下载包、Demo、计划或精选标记。Gitee 旧站的实际上传资源和内容数据尚未取得。

## 发布行为

作品与计划只有 `_status=published` 且 `visibility=public` 才可被匿名读取。草稿预览要求有效管理员身份。关联媒体具有独立公开开关，撤下作品会关闭作品下载入口，但已明确公开的媒体 URL 仍可访问；如需撤销文件访问，应同时关闭媒体的公开开关。

Demo 上传限制为 100MB，解压限制为 250MB、2500 个条目。拒绝路径越界、Windows 歧义路径、符号链接、加密包和重复路径；需要根目录或唯一顶层目录中的 `index.html`。每个版本在唯一临时目录验证后才移动到固定版本目录，失败时不会改动已有版本。

Demo 预览签名有效期 15 分钟，限定到单个版本并包含在预览路径中；相对资源路径会继承签名，不依赖沙箱页面的跨站 cookie。预览链接持有者在有效期内可访问，勿转发。Demo 主机名不提供主站、API 或后台。Demo 页面使用 CSP sandbox，资源允许跨源读取以支持沙箱中的模块脚本；相对路径的 HTML/CSS/JS 静态包可用，需要服务端、根路径硬编码、跨源隔离或特殊浏览器权限的项目需要另行适配。

## 后续可选扩展
